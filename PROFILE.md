## Unique Angles / Talking Points

### End-to-End Product Builder
Every project in this portfolio was taken from idea to deployed product, not just a code exercise. Pash (audio stem separator) required designing the user-facing React app, the FastAPI + Demucs ML backend, AWS infrastructure (S3, SQS, DynamoDB), OAuth authentication, GPU worker orchestration, and deployment automation — all as a single developer. The portfolio site itself (asmit.space) is a custom 3D interactive environment built with Three.js, complete with character movement physics, raycasting collision detection, a desktop-metaphor file browser, and an integrated full-stack audio app — demonstrating that "full-stack" means the entire surface area, not just a CRUD app with a React frontend.

### Problem Identifier, Not Just Problem Solver
At My Yoga Teacher, the challenge wasn't "build a voice recording UI" — it was "business users spend hours writing SQL to pull student health reports." The solution was a voice-to-SQL pipeline (Whisper ASR -> rule-based NLU with 9 intent patterns -> dynamic parameterized query builder) that turned a multi-minute manual process into a spoken sentence. At Nexus AI, customer support agents were drowning in repetitive policy questions — the answer was a RAG pipeline with 500+ embedded policy documents, semantic search via Pinecone, and a fine-tuned BERT intent classifier (95% accuracy across 7 categories) that grounded every response in actual company policy. The pattern: understand the human workflow bottleneck first, then engineer the right system to remove it.

### Polyglot Systems Thinker
Comfortable designing systems where the frontend is TypeScript/React, the API gateway is Go, the ML service is Python/FastAPI, and the database is PostgreSQL — all communicating cleanly through well-defined interfaces. The MYT NLP project ran exactly this stack in production with sub-second response times. This isn't about collecting languages; it's about choosing the right tool for each layer and making them work together.

### Ships Under Constraints
Built SentinalAI for the Voxel51 hackathon — real-time multi-model computer vision (YOLOv8 + pose estimation + facial detection) running in parallel on a single GPU at 30+ FPS, with privacy-first edge computing and zero cloud dependencies. Built Lynti Mobility to solve a real transportation problem in Northeast India with live tracking, route optimization, and real-time WebSocket updates. These aren't toy demos — they solve real problems under real constraints (time, hardware, connectivity).
