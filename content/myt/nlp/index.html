Key Engineering Achievements

  • Designed and implemented a full-stack microservices architecture using React 19 frontend, Go API gateway, Python FastAPI NLU service, and PostgreSQL database with clean separation of concerns across a polyglot system (TypeScript/JavaScript, Go, Python)
  • Built an end-to-end voice-to-SQL pipeline integrating OpenAI Whisper ASR for audio transcription, rule-based NLU engine with 9 intent recognition patterns, and dynamic SQL query builder that converts natural language to parameterized database queries in real-time
  • Developed a modern React application with Material-UI v7 featuring real-time voice recording (MediaRecorder API), advanced data visualization with MUI X DataGrid (sorting, filtering, pagination), dynamic column selection, and multi-format export functionality (CSV, XLSX)
  • Architected secure multi-tenant data access by designing a normalized PostgreSQL schema with 6 core tables, implementing teacher-based data isolation through student_concierge junction table, and ensuring row-level security with automatic teacher filtering on all queries
  • Implemented high-performance backend services with Go-based API gateway handling CORS, request routing, and PostgreSQL connection pooling, plus Python FastAPI service managing concurrent NLU processing and Whisper inference with sub-second response times
  • Leveraged ML/NLP technologies including PyTorch 2.7, OpenAI Whisper, spaCy 3.8, and SQLAlchemy 2.0 to enable hands-free business intelligence reporting, reducing query time from manual SQL writing to natural language voice commands
