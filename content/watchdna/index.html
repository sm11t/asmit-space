Key Engineering Achievements

  • Full-stack architecture and 58-field schema design implementing a comprehensive MongoDB document structure with nested objects for vendor details, services, pricing tiers, contact information, operating hours, and metadata to support complex watch repair business operations
  • Intelligent premium vendor classification algorithm analyzing multiple weighted factors including service breadth (luxury brand expertise, certification levels), customer ratings, response times, and service completeness to automatically categorize vendors into standard and premium tiers
  • CSV data pipeline with Python validation building automated ETL scripts for ingesting vendor data from spreadsheets, performing schema validation, type checking, geocoding address fields, and bulk importing 100+ records into MongoDB with error handling and rollback capabilities
  • Geospatial search with Haversine formula implementing location-based vendor discovery using MongoDB's geospatial indexes, calculating accurate distances between user coordinates and vendor locations, and returning sorted results within configurable radius parameters
  • Automated web scraping system developing Python scripts with BeautifulSoup and Selenium to extract vendor information from watch repair directories, handle dynamic JavaScript content, implement rate limiting, and validate extracted data against the database schema
  • JWT authentication and authorization securing the platform with JSON Web Token-based user authentication, implementing role-based access control (RBAC) for admin/vendor/customer roles, password hashing with bcrypt, and protected API endpoints with middleware validation
  • Interactive map interface (1,035 lines) creating a dynamic React component with Mapbox GL JS integration featuring custom vendor markers, info popup windows, zoom controls, location-based clustering for dense areas, and real-time filtering of visible vendors based on map bounds
Tech Stack
React.js • Node.js • Express.js • MongoDB • Mapbox GL JS • JWT • Python • BeautifulSoup • Selenium • Haversine • Geocoding API • bcrypt
