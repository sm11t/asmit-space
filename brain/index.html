// The Problem
LLMs forget.
Notes don't link.
Search is flat.

Every AI chat starts cold. Every note app is a list, not a mesh. Every Google search pulls strangers' opinions but not your own thinking from three weeks ago. There's no infrastructure for the thing you actually own: context about your own world.

🧊

No Continuity

LLMs forget everything the moment a session closes. Every question re-litigates context you already gave it. Your own research evaporates.

🕸️

No Connection

Notion, Apple Notes, Google Docs — all flat lists. Nothing tells you "this founder built the company you're tracking for your wedge." The links aren't wired.

🎛️

No Control

Cloud tools own your data, change pricing, kill features, lock exports. If your thinking depends on someone else's server, it's not really yours.

// The Agent Layer
One routing file.
Infinite commands.

cloud.md tells Claude Code how to navigate the vault. After that, you just talk: "run the morning brief", "ingest this URL", "who should I reach out to at AGI House?". The agent reads files, writes files, wikilinks, and logs itself into the daily note.

asmitsbrain — claude code
Claude Code Loop
A brain that works while you sleep.

The morning brief runs as a scheduled Claude Code job. It pulls overnight news, updates company notes, writes the daily log, flags new signals, and queues three questions for you by the time you pour coffee. You wake up already caught up.

  • ▸
    run the morning brief — web search + note updates + daily log, one command.
  • ▸
    ingest this: <url> — entity extraction + source note + bidirectional links.
  • ▸
    weekly review — synthesize themes, surface patterns, flag the top 3 wedges.
  • ▸
    what do we know about X? — the agent reads the note + all backlinks, gives you a briefing.
// Architecture
Six folders.
One agent.
Zero infrastructure.

No Postgres, no Pinecone, no Supabase. Just six folders of markdown files and a routing doc the agent reads first. The whole system is under a megabyte of plain text.

01
🧭

Context

Who you are, what you're building, what you're optimizing for. The agent reads this first so every response is calibrated to your mission, constraints, and strategy — not generic best practice.

about · mission · strategy · constraints
02
🧠

Intelligence

The knowledge base. Companies, people, industries, trends, papers — each one a markdown file with frontmatter, a ## Connections block, and bidirectional wikilinks into everything else.

companies · people · industries · trends
03
📅

Daily

One file per day. The agent writes the morning brief, logs what you worked on, captures decisions. Time-series memory — so next Tuesday you can ask "what did we decide last week?" and get a real answer.

daily · session log · decisions
04
🗺️

Maps

Maps of Content (MOCs) are curated index notes. [[AI-Agents-MOC]] lists every company in the ecosystem by layer. [[People-MOC]] is the priority reading list. They're your own table of contents.

MOCs · priority lists · thematic index
05
🚀

Projects

Live work: wedge trackers, startup hypotheses, position papers. Each one pulls intelligence from the rest of the vault and compounds over time. The wedge tracker is the place ideas either die or become theses.

wedge tracker · active work · hypotheses
06
✉️

Outreach

Lightweight CRM. Contacts from Apollo, drafts to review, sent archive. The agent personalizes every email using intelligence notes about the recipient — so "cold" outreach is actually warm because it references their real work.

contacts · drafts · sent archive
// How It Works With An LLM
Retrieval is a path.
Not a similarity score.

Traditional RAG crushes your notes into vectors and hopes cosine similarity brings back the right chunk. This system does the opposite — the agent walks explicit paths through a graph you authored. No embeddings. No guessing. The wikilinks are the retrieval plan.

// Positioning
Heavy AI stacks.
Lightweight beats them.

Most "AI memory" products demand a vector DB, an embedding pipeline, a retrieval API, and a multi-thousand-a-month bill. None of that is necessary. Wikilinks are explicit retrieval. The agent is the pipeline. The file system is the database.

No vector DB. No SaaS lock-in. No platform risk.
Just markdown files, wikilinks, and a Claude Code loop that reads one routing file first. The whole stack fits in a GitHub repo and runs on a laptop.
You can back it up with git. You can read it in Notepad. You can port it to Logseq tomorrow. The data outlives every tool you run on top of it — including this one.
